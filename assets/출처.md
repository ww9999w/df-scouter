# 아이콘 출처

원본 PNG를 그대로 포함했습니다. 화면에서 크기만 조절하며 이미지 파일 자체는 편집하지 않았습니다.

## 정밀도 단계 어셋 (2.5.0)

사용자가 준비한 `perfume-0..4.png`, `cube-0..4.png`, `heart-0..4.png`, `eye-0..4.png`를 현재 표시용으로 사용합니다. 모두 28×28이며 파일 내용을 변경하지 않았습니다.

공식 프로필 URL의 끝 번호 `0, 1, 2, 3, 100`을 각각 로컬 단계 `0, 1, 2, 3, 4`로 대응합니다. 종류별 공식 경로는 다음과 같습니다.

| 종류 | 공식 URL 패턴 | 로컬 패턴 |
|---|---|---|
| 향수 | https://resource.df.nexon.com/ui/img/web/equipment/o_{0,1,2,3,100}.png | perfume-{0,1,2,3,4}.png |
| 큐브 | https://resource.df.nexon.com/ui/img/web/equipment/only-cube-{0,1,2,3,100}.png | cube-{0,1,2,3,4}.png |
| 심장 | https://resource.df.nexon.com/ui/img/web/equipment/only-disease-{0,1,2,3,100}.png | heart-{0,1,2,3,4}.png |
| 눈동자 | https://resource.df.nexon.com/ui/img/web/equipment/only-michaela-{0,1,2,3,100}.png | eye-{0,1,2,3,4}.png |

아래의 `unique-*.png`는 구버전 자료로 보존하며 현재 단계 판정의 기본값으로 사용하지 않습니다.

| 파일 | 공식 URL |
|---|---|
| fame.png | https://resource.df.nexon.com/ui/img/world/ico_fame.png |
| equipment-score.png | https://resource.df.nexon.com/ui/img/world/ico_equi.png |
| buff-score.png | 공식 캐릭터 프로필 SingleFile의 `.char_cardbox dl dd.fame p.buff::before` CSS에 포함된 PNG 원본 (15×15) |
| mist-level.png | https://resource.df.nexon.com/ui/img/eff/fog.png |
| black-abyss.png | 사용자가 첨부한 흑아 아이콘 PNG 원본 |
| unique-perfume.png | https://resource.df.nexon.com/ui/img/web/equipment/o_100.png |
| unique-cube.png | https://resource.df.nexon.com/ui/img/web/equipment/only-cube-100.png |
| unique-heart.png | https://resource.df.nexon.com/ui/img/web/equipment/only-disease-100.png |
| unique-eye.png | https://resource.df.nexon.com/ui/img/web/equipment/only-michaela-100.png |

black-abyss.png는 2.3.0부터 사용자가 제공한 이미지 원본을 그대로 사용합니다. 실제 흑아 보유 부위는 캐릭터 장비 데이터로 계산하며, 보유하지 않으면 아이콘을 표시하지 않습니다.
